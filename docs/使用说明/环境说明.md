# 环境说明

## 运行要求

| 组件 | 要求 |
|---|---|
| Shop、Agent Hub、Agent Cluster | Python 3.11、uv |
| 独立数据中台 | Python 3.14、uv |
| 数据库 | PostgreSQL，安装pgvector扩展 |
| 前端构建 | Node.js 20.19及以上的20.x版本，或22.12及以上版本；npm |
| 文件检查 | 系统提供`file`命令 |
| 文档转换 | Docling模型文件、`cl100k_base` Tokenizer缓存；扫描PDF使用Tesseract OCR |

依赖版本由根目录、`agent-hub/`、`agent-cluster/`及`data-center/`中的`uv.lock`锁定，前端依赖由`frontend/package-lock.json`锁定。安装及启动命令见[命令说明](命令说明.md)。

## Shop配置

将[.env.example](../../.env.example)复制为根目录`.env`，根据部署环境填写。

| 配置 | 用途 |
|---|---|
| `SHOP_DATABASE_URL` | Shop数据库连接，默认本机55432端口的`shop`数据库 |
| `SHOP_DATA_DIR` | 素材与业务数据目录 |
| `SHOP_SESSION_SECRET_FILE` | 会话密钥文件 |
| `SHOP_ADMIN_PASSWORD_FILE` | 初始化管理员密码的保存位置 |
| `SHOP_PROVIDER_ENV_FILE` | 模型提供商配置文件 |
| `SHOP_UPLOAD_MAX_BYTES` | 上传大小限制，默认32 MiB |
| `SHOP_CLUSTER_CONFIG_FILE` | Agent Cluster配置文件；填写后启用集群入口 |
| `SHOP_CLUSTER_NOTES_DIR` | Note目录 |
| `SHOP_DATA_CENTER_URL` | 独立数据服务地址，启用数据中台时填写 |
| `SHOP_DATA_CENTER_SOURCE_ROOT` | 数据中台原始资料目录 |
| `SHOP_DATA_CENTER_SERVICE_TOKEN_FILE` | Shop与数据服务共享的服务身份文件 |

本地数据库脚本使用`SHOP_POSTGRES_BIN`指定PostgreSQL可执行文件目录，数据库保存在`.local/postgres`，监听`127.0.0.1:55432`。脚本使用本机trust认证；共享部署需要自行配置数据库认证和网络访问权限。

## 模型凭据

在`SHOP_PROVIDER_ENV_FILE`指定的文件中填写`DEEPSEEK_API_KEY`、`DASHSCOPE_API_KEY`和`DASHSCOPE_BASE_URL`。DashScope地址使用北京地区官方OpenAI兼容接口，路径为`/compatible-mode/v1`。凭据文件保存在`.local/auth/`等Git忽略目录，文件权限使用`0600`。

模型调用、图片索引、embedding和问答需要网络，会产生提供商费用。业务模型配置与用量记录由Shop管理。集群协调模型可配置DeepSeek或Qwen，参数格式见[Agent Cluster](../../agent-cluster/README.md)。

## Agent Hub与Cluster配置

根据[Hub配置示例](../../agent-hub/config.example.json)填写后端地址、账号、密码文件和`expected_actor_id`，登记需要使用的Agent及共享工具。`expected_actor_id`取认证登录响应中的`id`；相对密码路径从Hub配置文件所在目录解析。

集群配置的`actors`使用同一账号编号作为键，并填写Hub进程的Python绝对路径、配置路径和工作目录。`autorun`控制目标自动执行，协调模型由`profile`配置。完整格式见[Agent Hub](../../agent-hub/README.md)和[Agent Cluster](../../agent-cluster/README.md)。

## 独立数据中台配置

数据服务通过进程环境读取`DATA_CENTER_`配置。Shop读取根目录`.env`；数据服务所需变量传入其启动进程。

| 配置 | 用途与默认值 |
|---|---|
| `DATA_CENTER_DATABASE_URL` | 独立库连接，默认本机55432端口的`shop_data_center`，账号为`data_center_writer` |
| `DATA_CENTER_SHOP_URL` | Shop地址，默认`http://127.0.0.1:8002` |
| `DATA_CENTER_SERVICE_TOKEN_FILE` | 服务身份文件，默认`.local/auth/data-center.service.key` |
| `DATA_CENTER_ARTIFACT_ROOT` | 文档、计算结果和运行记录目录，默认`.local/data-center` |
| `DATA_CENTER_MODEL` | 问答模型，支持`deepseek-flash`与`qwen3.8-flash` |
| `DATA_CENTER_GRAPH_ENABLED` | 图索引构建开关，默认`false` |
| `DATA_CENTER_GRAPH_MODEL` | Graph计算模型，支持`deepseek-flash`与`qwen3.8-flash` |
| `DATA_CENTER_DOCLING_MODELS` | Docling模型目录，默认`.local/data-center/models/docling` |
| `DATA_CENTER_TOKENIZER_CACHE` | Tokenizer缓存目录，默认`.local/data-center/tiktoken` |
| `DATA_CENTER_TESSERACT_COMMAND` | OCR命令，默认`tesseract` |

Shop的`SHOP_DATA_CENTER_URL`指向数据服务，数据服务的`DATA_CENTER_SHOP_URL`指向Shop；双方服务身份文件的内容必须一致。数据库初始化与服务身份准备命令见[命令说明](命令说明.md)。

文档转换使用本地Docling模型与Tokenizer缓存。转换进程的`TIKTOKEN_CACHE_DIR`应与`DATA_CENTER_TOKENIZER_CACHE`指向同一目录。资料、向量和分析快照保存在本地；模型服务处理提交的计算输入。

文档问答默认使用`retrieval_mode="hybrid"`。Graph源码及LightRAG依赖保留，默认配置关闭新图索引构建。开关控制构建，已有历史查询继续遵循缓存与权限规则。

## 账号与来源

素材管理使用Shop账号权限；客服订单通过服务端CustomerID绑定。考核使用独立`AssessmentAccess`配置本人、指定团队或组织范围，Shop管理员也需要单独的考核授权。

考核订单来源通过`SHOP_ASSESSMENT_ORDER_ADAPTER`、`SHOP_ASSESSMENT_ORDER_DATABASE_URL`和`SHOP_ASSESSMENT_ORDER_SOURCE_FILE`配置。内置AdventureWorks适配器支持`2023-07-01`至`2023-10-01`的考核期间。员工和目标来源通过命令导入。

数据中台来源登记和授权由管理员配置。同步操作使用`data_sync`专用账号，文档及经营分析读取按来源授权；联合问题需要同时具备相关文档和考核权限。资料来源、输入字段与引用格式见[接口说明](接口说明.md)。

素材样例来自固定版本的Fashion数据，历史订单及员工样例来自Microsoft AdventureWorks。数据许可、当前商品价格、库存与政策由使用者按实际业务来源配置；辅助图库仅供其许可范围内的研究使用。

## 文件保存

凭据、数据、Note和生成文件使用`.local/`，缓存和中间记录使用`.scratch/`，两个目录均由Git忽略。迁移到其他机器时分别准备运行配置、数据库和需要使用的资料；源码发布包包含代码、依赖文件和使用说明。
