# 接口说明

## 公共HTTP调用

通过`POST /api/login`使用自己的账号登录，后续请求携带会话cookie。`GET /api/modules`返回当前登记的模块、操作及完整输入输出JSON Schema。

统一操作入口为`POST /api/modules/{module_id}/operations/{operation}`，输入格式为：

```json
{
  "version": "1",
  "request_id": "616ae3f3-c067-4f4d-8b96-166ae04c5b1a",
  "payload": {"limit": 5, "offset": 0},
  "upstream": []
}
```

`payload`使用目录登记的输入Schema，`upstream`携带先前产物的`ResourceRef`。账号和授权来自认证身份。同一账号、操作、请求编号与内容复用；使用相同编号改变输入会被拒绝。

返回的`OperationResult`包含`status`、`data`、`resources`、`run_id`与`costs`。持续任务根据返回编号调用对应的`show`或查询操作；状态与产物完成情况按实际结果读取。

## 模块与授权

| `module_id` | 能力及授权 |
|---|---|
| `materials` | 素材查询与版本读取；保存要求管理员权限 |
| `harness` | 宣传页面任务、执行、恢复和取消；普通账号访问本人任务 |
| `customer` | 本人订单、会话、消息与工单；订单使用服务端CustomerID绑定 |
| `assessment` | 考核任务、指标及依据；读取范围使用独立`AssessmentAccess` |
| `poster` | 关键词准备、业务角色与海报任务；按任务与输入素材授权 |
| `data_center` | 来源、文档、分析与导出；检查账号来源权限及服务身份 |

各操作的必填字段、范围和返回类型以运行目录中的Schema为准。资源文件通过`GET /api/modules/{module_id}/resources/{resource_id}/files/{relative_path}`读取，可携带资源类型、版本和SHA-256进行核查。

## MCP与其他Agent接入

[Agent Hub](../../agent-hub/README.md)通过MCP stdio提供整体Agent与两个共享素材工具。`list_agents`返回允许的能力及每项操作的Schema；Agent调用携带`action`、`payload`、`request_id`和`upstream`。

新服务实现异步`BackendConnector.describe()`、`invoke()`、`read_file()`和`close()`，通过Registry登记整体Agent及需要共享的工具。公共层沿用原业务Schema，各Agent内部工具按模块管理。

公共协议类型见[integration_protocol](../../packages/integration-protocol/src/integration_protocol/__init__.py)，HTTP宿主见[integration_host](../../packages/integration-host/src/integration_host/host.py)。目标、完成条件、日程和Note类型见[agent_cluster.types](../../agent-cluster/src/agent_cluster/types.py)，宿主与模型接入见[Agent Cluster](../../agent-cluster/README.md)。

## 数据中台输入

| 类型 | 用途 |
|---|---|
| `SourceRegistration` | 来源编号、修订、许可、资料性质、摘要与受控路径；文档绑定原件`ResourceRef` |
| `GrantRegistration` | 来源、被授权账号、允许操作和资料范围 |
| `DocumentIngest` | 登记资料、文档转换及片段配置；`graph_enabled`默认关闭 |
| `DataQuestion` | 中文问题、候选来源、可选必需来源及检索模式 |
| `DataQuery` | 明确的文档、业务或指标查询，包含条件及快照 |
| `DataEvidenceRef` | 来源、修订、快照、摘要与文档位置或业务记录编号 |

完整字段与校验规则见[data_center_protocol](../../packages/data-center-protocol/src/data_center_protocol/__init__.py)。文档原件放在`SHOP_DATA_CENTER_SOURCE_ROOT`内，登记内容核查相对路径与SHA-256。

文档问答默认`retrieval_mode="hybrid"`。`source_ids`指定候选来源，`required_source_ids`指定必须共同引用的来源子集。指标日期区间包含`start_date`，不包含`end_date`；指标和维度来自已登记目录。

`ask`提交后返回持久任务编号；`show`读取结果，`run`继续原任务，`cancel`取消任务。`reference`回读原始依据，`export`提供Markdown或CSV文件。资料不足、权限不足或来源撤回时，结果提供具体原因。

来源管理使用`register_source`、`set_grant`和`withdraw_source`；资料转换与同步使用`ingest`和`sync`。相同来源修订重复登记可以复用；内容或来源说明改变时登记新的修订。自动来源检查通过`POST /api/data-center/automation`安装，目标控制沿用集群API。
